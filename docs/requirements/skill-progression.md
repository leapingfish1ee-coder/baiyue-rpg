# 技能成长

状态：已确认产品设计基线。

> 本文中的等级上限、升级曲线、里程碑间隔、速度加成、持续时间下限和目标熟练度阈值均为“首轮平衡基线”，不是已实现事实。首次稳定存档格式确定前可以通过明确的平衡决策调整。

## 核心决策

Baiyue RPG 采用“单角色全技能可学 + 时间、当前任务和装备形成软专精 + 后期按内容规模决定是否增加目标熟练度”。

- 不设置职业、转职、技能点、天赋树、洗点或永久互斥选择。
- 不采用脱离玩法行动、按现实时间自动增长的被动训练。
- 玩家决定行动类别和目标；系统只负责索取目标、寻路、执行和处理中断。
- 玩家最终可以掌握全部已发布技能，但不能同时高效完成全部活动。
- 移动、待机、失败、受伤和死亡均不直接授予经验。

“狩猎”和“生产”是任务类别，不是技能。狩猎根据实际战斗方式训练战斗技能；生产根据具体配方训练 `锻造` 或 `工艺` 等生产技能。

## 首个端到端版本的技能

首个端到端版本固定包含以下 `8` 项技能。`8` 是版本范围，不是平衡参数。

| 技能 | 有效结算 | 首版能力或内容边界 |
|---|---|---|
| `探索` | 首次揭露地图；首次发现内容 | 唯一能力效果是提高有效观察半径 |
| `潜行` | 完整通过一次本可触发战斗的非狩猎目标敌人威胁区，且未被发现 | 降低敌人发现概率 |
| `采集` | 成功取得植物、纤维或地表散落自然材料 | 解锁和加速对应资源行动 |
| `伐木` | 成功完成一次木材资源行动 | 解锁和加速对应木材行动 |
| `采矿` | 成功完成一次矿石或石材资源行动 | 解锁和加速对应矿石/石材行动 |
| `锻造` | 成功完成金属材料、金属工具、武器或防具配方 | 解锁和加速对应配方 |
| `工艺` | 成功完成木、皮、纤维等非金属工具、装备或通用物品配方 | 解锁和加速对应配方 |
| `近战` | 使用近战方式完成击杀 | 解锁近战内容；击杀时结算经验 |

后续只有在对应玩法端到端成立后才增加 `远程`、`烹饪`、`炼金`、`捕鱼` 等技能。`魔法` 必须等待世界观和战斗资源设计确认；当前不得预留空技能、空经验条或占位接口。

所有当前已发布技能从等级 `1` 开始，且同一角色均可训练。高级技能可以通过世界发现、叙事或其他世界内容解锁，但不能形成互斥职业。

## 等级、准入与里程碑

- 每项技能等级范围为 `1–100`，`100` 是当前上限；不显示虚拟等级。该范围是首轮平衡基线。
- 永久基础等级决定目标、配方、工具、装备、区域和行动的准入。
- 装备和临时效果不能绕过等级要求。
- 每 `10` 级形成一个主要里程碑。该间隔是首轮平衡基线。
- 具体内容在内容表中声明所需等级，不能只依赖通用里程碑推断。

技能页展示要求见[玩法 UI](gameplay-ui.md#技能页)。

## 升级曲线

从等级 `L` 升至 `L+1` 所需经验为：

```text
round(100 × 1.12^(L-1))
```

适用范围为 `1 ≤ L < 100`。系数 `100`、增长率 `1.12`、四舍五入规则和 `100` 级上限均为首轮平衡基线。

`SkillProgress` 保存累计经验和由同一版本曲线推导的等级。调整曲线时必须显式决定游戏规则版本和存档 schema 处理方式；技能平衡变化不得修改地形 `GENERATOR_VERSION`。

## 有效结算与经验来源

技能经验必须能追溯到一次有效结算：

| 活动 | 获得经验 | 不获得经验 |
|---|---|---|
| 探索 | 首次揭露世界单元；首次发现地标、资源类型、敌人类型或叙事线索 | 重复经过、单纯移动、待机、不可达或失败 |
| 采集/伐木/采矿 | 成功完成一次对应资源行动 | 寻路、尝试失败、资源无效、等待重生、待机 |
| 锻造/工艺 | 对应配方完整产出一次 | 缺料、被取消的周期、等待条件、待机 |
| 潜行 | 完整通过一次有效威胁区，且未被发现 | 无威胁经过、重复判定、狩猎目标、被发现、战斗、待机 |
| 近战 | 使用近战方式完成一次击杀 | 每次攻击、命中、受伤、逃离、未击杀、玩家死亡 |

敌人强迫进入的战斗与主动狩猎使用同一击杀经验和掉落规则。死亡本身不扣除已获得经验，也不授予经验。

### 资源与生产经验

`采集`、`伐木`、`采矿`、`锻造`、`工艺` 按成功完成一次行动结算固定经验。额外产量不额外授予经验。

行动基础经验按以下方法形成首轮内容建议，再由内容表固定为明确值：

```text
基础经验建议 = 基础持续秒数 × 内容阶级系数
```

实际耗时、速度加成和额外产量不改变该次基础经验。内容阶级、系数和最终经验值必须由内容表声明；本文不补造首批内容数值。

### 探索经验

探索按首次揭露的世界单元结算。地标、资源类型、敌人类型和叙事线索的首次发现可以提供内容表规定的固定奖励。同一世界单元或同一发现记录不能重复提供首次经验。

世界单元粒度和各类固定奖励仍需随地图内容表确定；不得用移动距离或在线时间代替首次揭露结算。

### 潜行经验

潜行只在角色完整通过一次有效敌人威胁区且未被发现后结算。同一敌人生成实例最多结算一次潜行成功。狩猎目标不触发潜行成功，也不提供潜行经验。

威胁区、遭遇身份和确定性判定见[战斗与潜行](combat-stealth.md#确定性遭遇判定)。

### 战斗经验包

当前只有 `近战`，近战击杀的经验包全部结算到 `近战`。不得按攻击次数、最后一击或武器切换结算。

未来加入多种战斗方式后，每次击杀仍只生成一个经验包，再按各方式对该敌人造成的有效伤害占比分配。过量伤害不计入有效伤害。该规则防止最后一击切换武器获利；具体战斗技能和分配实现只在相应玩法进入范围后定义。

## 任务计数、产量与经验

任务数量按实际产出或实际目标击杀计数。额外产量可以增加物品和任务计数，但不改变单次基础经验。

```text
一次成功资源或生产行动
  ├─ 物品：按实际完整产量结算
  ├─ 任务计数：按实际目标产量结算
  └─ 技能经验：按一次有效行动的固定经验结算
```

该边界防止技能等级同时放大产出、任务进度和经验。任务详细语义见[自动任务](automation-tasks.md)。

## 技能效果

技能等级的首要价值是解锁内容，次要价值是有上限的行动效率。

### 资源与生产速度

`采集`、`伐木`、`采矿`、`锻造` 和 `工艺` 使用以下首轮平衡基线：

- 每高于目标所需等级 `1` 级，技能来源的行动速度增加 `0.5%`。
- 技能来源速度加成最多 `25%`。
- 叠加所有来源后，总行动持续时间不得低于该行动基础持续时间的 `25%`。

技能来源和装备来源必须分别计算、分别显示。具体叠加公式需在实现前形成统一规则；无论采用何种公式，都必须守住上述技能加成上限和最短持续时间下限。

### 明确不由等级提供的效果

技能等级本身不提高额外产量、品质或稀有掉落。这些能力只能来自装备、内容奖励或后续目标熟练度，且必须明确来源。

首版生产在材料、工具和永久基础等级满足时必定成功，不设置随机失败或品质等级。

## 装备软专精

- 工具、武器、防具和饰品提供可逆软专精。
- 装备只能在非战斗状态更换。
- 更换装备不损失技能等级、累计经验、任务外永久进度，也不需要重置费用。
- 装备加成必须说明来源，并与技能等级加成分别显示。
- 首个端到端版本不自动换装。

## 后续目标熟练度

目标熟练度不进入首个端到端版本。只有某技能已有至少 `8` 个有意义且长期重复的目标或配方，并且技能等级无法表达玩家选择时，才引入。阈值 `8` 是首轮平衡基线。

若引入，遵守以下已确认边界：

- 每个目标独立拥有 `1–100` 熟练度。该范围是首轮平衡基线。
- 行动只增加对应目标熟练度。
- 等级 `25/50/75/100` 提供目标专属里程碑。这些节点是首轮平衡基线。
- 不采用共享熟练度池。
- 熟练度可以从行动速度、额外产量、材料节省、稀有掉落中选择有限效果，不得同时叠加所有维度。
- 敌人目标熟练度如加入，只影响追踪或该敌人的战利品信息，不直接提高通用战斗伤害。

目标熟练度进入实现前，仍需为具体技能和目标确定效果维度、曲线、存档字段与验收标准。

## 首个端到端版本范围

必须包含：

- 上述 `8` 项技能；
- 等级、累计经验、升级曲线和内容准入；
- 有效结算经验；
- 当前经验、下级经验、下一里程碑和加成来源展示；
- 装备软专精边界。

明确排除：职业、转职、技能点、天赋树、洗点、训练焦点、目标熟练度、现实时间被动训练，以及尚未进入范围的 `远程`、`魔法`、`烹饪`、`炼金`、`捕鱼`。

## 验收标准

- 所有已发布技能均能由同一角色训练，并从等级 `1` 开始。
- 永久基础等级是内容准入依据；装备和临时效果不能越级解锁。
- 任何技能经验都能追溯到一次有效结算。
- 移动、待机、失败、受伤和死亡不直接提供经验。
- 额外产量增加物品和任务计数，但不增加单次固定经验。
- 实际耗时和速度加成不改变行动基础经验。
- 潜行成功和敌人生成实例一一对应；狩猎目标不提供潜行经验。
- 当前近战击杀只生成一次经验包；攻击次数和最后一击换装不能增加经验。
- 生产在材料、工具和基础等级满足时必定成功。
- 技能等级不直接提高产量、品质或稀有掉落。
- 装备只能在非战斗状态更换；更换不损失技能进度或产生重置费用。
- UI 不展示虚拟等级、未发布技能或首版排除系统。
